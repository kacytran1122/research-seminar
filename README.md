# Research Seminar: Sentinel-2 / ICESat-2 Multimodal Fusion

Anonymous-author research package for a TGRS-style remote-sensing manuscript.

- `paper/main.tex` — IEEEtran manuscript source.
- `paper/research_seminar_tgrs_manuscript_ieee.pdf` — compiled IEEE-format manuscript PDF.
- `paper/figures/` — publication figures and architecture diagram.
- `paper/tables/` — metric tables from real training artifacts.
- `reproducibility/metrics_provenance.json` — source/provenance record for reported numbers.

No mock data or fake metrics are included.
